# Авто Мото Україна 🇺🇦

Простий Telegram-бот для створення та пошуку оголошень. Працює на Python (aiogram + FastAPI), Render Starter та SQLite на постійному диску.

## Render

- Web Service з репозиторію GitHub, план Starter (платний).
- Диск: `/var/data`, 1 GB. База: `/var/data/automoto.db`.
- Build: `pip install -r requirements.txt`.
- Start: `uvicorn app:app --host 0.0.0.0 --port $PORT`.
- Health check: `/`.

## Секретні змінні (Environment)

- `BOT_TOKEN` — токен Telegram із BotFather (не публікувати).
- `WEBHOOK_SECRET` — випадковий секрет (можна згенерувати в Render).
- `PUBLIC_URL` — URL сервісу, наприклад https://automoto-ua-bot.onrender.com (без слеша в кінці).
- `SQLITE_PATH` — `/var/data/automoto.db`.

## Публікація в групах (за потреби)

Опціональні змінні: `GROUP_AUTORINOK`, `GROUP_AGRO`, `GROUP_PARTS`, `GROUP_TRUCKS`, `GROUP_MOTO`. Значення — ID відповідних Telegram-груп; бот повинен мати право публікувати повідомлення. Поки ID відсутній, оголошення зберігається і доступне в пошуку, але не публікується у групу.

## Важливі обмеження MVP

- Стан створення оголошення тимчасово зберігається в оперативній пам'яті: після перезапуску незавершене оформлення потрібно почати заново.
- Пошук текстовий, повертає останні 10 результатів.
- Не налаштовано резервне копіювання SQLite, складну антиспам-модерацію та редагування оголошень.
- Не запускайте два екземпляри бота з тією самою базою та webhook.
- До активного публічного запуску перевірте коректність налаштування, обмеження повідомлень і правила модерації.
